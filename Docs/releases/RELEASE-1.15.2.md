## Arcanes & Scénario 1.15.2

Placer les valeurs sur une feuille PDF éditable devient presque automatique.

### Nouveautés

- **Import d'un PDF éditable** : les zones de saisie et les cases à cocher du formulaire sont repérées à l'import ; les cases voisines sont regroupées en une rangée.
- **Aimantation des zones** : dans « Placer les valeurs », les champs du PDF s'affichent ; un clic pose la zone choisie dessus, et une zone lâchée près d'un champ s'y colle.
- **Aimanter tout** : chaque zone déjà placée se colle sur le champ le plus proche (90 zones sur 91 sur la feuille D&D 5 française).
- **Placer d'après les noms** : les éléments pas encore placés prennent le champ du PDF dont le nom leur ressemble.

### Améliorations

- Les systèmes fournis sont désormais des fichiers : on peut en ajouter sans toucher au code (voir Docs/Ajouter-un-systeme.md).

### Utilisation

- Page Jeu › Fond de feuille : importez votre PDF éditable (ou réimportez-le : un fond déjà importé n'a pas de champs), puis « Placer les valeurs ». Les placements restent modifiables et ne sont enregistrés qu'avec « Enregistrer le placement ».

### Installation

- Mise à jour depuis Paramètres › À propos, ou installateur / APK de la release.
