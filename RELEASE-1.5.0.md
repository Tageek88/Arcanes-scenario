## Arcanes & Scénario 1.5.0 — Génération aléatoire : bases et noms

Cette version ajoute la génération aléatoire de noms pour les PNJ, lieux et indices, cohérents avec l'univers de jeu choisi.

### Nouveautés

- **Univers de jeu** : choisissez un type d'univers lors de la création d'une campagne (Arcanes, Fantasy héroïque, Horreur cosmique, Gothique, Cyberpunk, Opéra spatial) pour adapter la génération de noms.

- **Génération de noms de PNJ** : depuis le formulaire de création ou de modification d'un PNJ, cliquez sur « Génération aléatoire » pour produire un nom cohérent avec l'univers et le sexe choisi (neutre, masculin ou féminin).

- **Génération de noms de lieux** : depuis le formulaire de création ou de modification d'un lieu, cliquez sur « Générer des noms de lieux » pour produire trois propositions. Sélectionnez la plus appropriée pour remplir le champ nom.

- **Génération de noms d'indices et d'infos** : depuis le formulaire de création ou de modification d'un indice ou d'une info, cliquez sur « Générer des noms d'indices/infos » pour produire trois propositions adaptées au type d'univers.

- **Bouton « Modifier la campagne »** : depuis l'onglet Arborescence, le bouton ouvre le formulaire de modification pour changer le type d'univers ou le système de jeu de la campagne.

### Améliorations

- **Fallback intelligent** : si un univers n'a pas ses propres données de lieux ou indices, la génération utilise automatiquement les données de l'univers « Arcanes » pour garantir des résultats.

- **Interface centralisée** : les boutons de génération apparaissent directement sous le champ nom, avec la liste des propositions cliquables juste en dessous.

### Corrections

- **Affichage des données d'univers** : le chargement de l'univers de jeu fonctionne maintenant pour tous les types de fiches (PNJ, lieux, indices), pas seulement les PNJ.

### Utilisation

**Générer un nom de PNJ** : ouvrez une fiche de PNJ, sélectionnez le sexe souhaité dans le menu déroulant « Genre du nom généré », puis cliquez sur « Génération aléatoire ». Le champ nom se remplit automatiquement.

**Générer des noms de lieux ou indices** : ouvrez une fiche de lieu ou d'indice, cliquez sur « Générer des noms de lieux » ou « Générer des noms d'indices/infos ». Une liste de trois propositions s'affiche ; cliquez sur celle que vous préférez pour la remplir dans le champ nom.

**Modifier l'univers** : depuis l'onglet **Arborescence**, cliquez sur le bouton « Modifier la campagne » pour ouvrir le formulaire de modification. Changez le type d'univers et cliquez sur « Enregistrer ». Les générations futures utiliseront le nouvel univers.

### Installation

Téléchargez `Arcanes Scenario Setup 1.5.0.exe` et lancez-le. Windows SmartScreen peut afficher un avertissement (programme non signé) : « Informations complémentaires », puis « Exécuter quand même ».

⚠️ Les données sont propres à chaque installation. Exportez une sauvegarde depuis **Paramètres** avant toute réinstallation.
