## Arcanes & Scénario 1.3.3

###Nouveautés
-**Système de jeu par campagne** : définissez un modèle de fiche avec les caractéristiques et les champs souhaités — modificateur, seuil de test, maximum et modificateur de lancer pour les compétences.
-**Fiches de personnages** : créez, modifiez et dupliquez des fiches contenant les caractéristiques, compétences, équipements et notes du personnage.
-**Catalogues de compétences et d’équipements** : les éléments saisis sont retenus pour la campagne. Après confirmation, les champs d’une compétence déjà connue peuvent être repris.
-**Champs d’équipement réutilisables** : les champs facultatifs déjà définis pour un type d’équipement sont proposés pour les nouveaux objets de ce type.
-**Seuils de test saisis manuellement** : l’application ne calcule pas la difficulté; la valeur entrée est conservée lors de la duplication.

### Installation
Téléchargez `Arcanes Scenario Setup 1.3.2.exe` et installez le par-dessus la version précédente. La sauvegarde automatique n'existe que dans le programme installé, pas dans le navigateur.
